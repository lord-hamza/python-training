# Python in 30 Days

One topic per day. Open the folder whose number matches the day. Each topic is a folder with 3 files: two practice questions and one LeetCode
problem, written as comments at the top. Solve every file, push every day.

**Daily routine:** read the 3 questions → Google/YouTube anything you don't know → solve →
run → `git add` / `commit` / `push`. From Day 14 onward, every day's work goes on a branch.

## Ground rules

- Solve every question in the file it's given in. Keep the question comments — your solution goes below them.
- Every LeetCode file has a runnable `__main__` block with expected outputs. Run it locally before submitting.
- If a question says "write in a comment why…", actually write it. Explaining is how you find out you don't know.
- Stuck for more than 30 minutes? Search for the *concept*, not the solution.
